# agent-purge v0.2.35

## Windows desktop fixes (#20)

- Statically link the window host and thin launcher against the MinGW runtime rather than depending on `libgcc_s_seh-1.dll`, `libstdc++-6.dll`, or `libwinpthread-1.dll` outside the installer. The build checks the import table and refuses release if dynamic dependencies are found or cannot be checked.
- If the native window fails immediately at startup, record a diagnostic log and fall back to a browser. Singleton registration uses the actual fallback window PID.
- Fixed duplicate windows caused by a focus failure with a restricted PATH; the system PowerShell path is now used consistently.
- Running launchers and native windows prevent the installer from replacing or deleting program files, avoiding uninstall leftovers.

## Safe uninstall and preview

- Uninstall reverses takeovers only after user confirmation. Canceling leaves configuration unchanged.
- Old files or custom ledgers that cannot be undone can be skipped with a record, leaving recovery credentials in place. Serious configuration, ledger-read, active-channel, or PATH errors still stop uninstall.
- Fixed a secondary exception triggered by corrupt configuration and repeated handling of already restored files.
- `clean --dry-run` and `self-uninstall --dry-run` do not initialize or migrate user data, roll back journals, or write logs.
- Removed the exclusive badge for consistent tool presentation; separate persona selection and DSH form settings remain.

## Verification and cross-platform artifacts

- Fourteen Windows acceptance checks covering actual installation, reinstallation, windows, singleton behavior, closing, conflicts, and uninstall passed, and the test was checked not to have changed real user configuration.
- The release process checks Windows, Linux, and macOS across Node 20, 22, and 24.
- Linux x64 and ARM64 each run native-architecture acceptance tests for the standalone binary, portable installation, Debian package install/run/uninstall, and optional AppImage, rather than cross-compiling only.
- Artifacts include Windows ZIP, setup, and standalone EXE; Linux x64/ARM64 standalone, tar.gz, deb, and optional AppImage; and macOS arm64/x64 DMG. Checksums are in the Release's `SHA256SUMS.txt`.
- The macOS DMG remains unsigned and unnotarized; on first launch, manually allow it through the system security prompt.
