# agent-purge v0.2.17

### Highlights

#### 1. PI-Desktop channel, including real-machine hot-switch testing

- **Detection**: Uses the `~/.pi-desktop` data root and installation directory, including `PI-Desktop-Portable-*.exe`, without confusing pi CLI for PI-Desktop.
- **Persistent**: Writes a managed block in `~/.pi/agent/SYSTEM.md`, replacing the product persona block (64 KiB limit), effective in new sessions.
- **Hot switching**: From PI-Desktop 0.21 onward, extensions must be contributed by plugins (ADR 0215). agent-purge installs an imported plugin in `plugins/imported/agent-purge` and registers it; `before_agent_start` reads `state.json` each turn.
- **Observed test**: Changing the state persona during one session changed the next response; `/purge off` restored the default. The first plugin installation requires a PI-Desktop restart. Correction dated 2026-11-15: version 0.21 sends `before_agent_start` replacements as mid-session system patches; models that reject such patches, such as mercury-3, will not show the change. The current version also writes `systemPromptOptions.forceSystemPrompt` for full replacement independent of model.

#### 2. Executable wildcard matching

`locate()` supports versioned portable names such as `PI-Desktop-Portable*.exe`. Wildcards apply only when `*` is explicit, so `Antigravity.exe` does not incorrectly match `antigravity-tools.exe`.

#### 3. Removed unsupported channels

Removed TRAE CN and Qoder CN harnesses because they offer only rule or memory layers and cannot replace the system prompt, avoiding a misleading suggestion that they can change identity.

### Installation and upgrade

```bash
npm install -g agent-purge@latest
agent-purge web
```
