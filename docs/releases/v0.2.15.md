# agent-purge v0.2.15

### Highlights

#### 1. Portable and installed versions exit the background service when the window closes (Issue #7)

- **Heartbeat and timeout**: The server's `autoExit` mechanism releases the HTTP port and exits safely when the Web window closes and its heartbeat stops for over 8 seconds, allowing time for an F5 refresh, or when no connection arrives within 30 seconds of launch.
- **Page unload notification**: The Web frontend uses `navigator.sendBeacon('/api/exit')` on `pagehide` to notify the backend to exit immediately.
- **Explicit exit button**: The console's top-right Exit button calls `/api/exit` after confirmation, gracefully stopping the service and closing the browser window.
- **Automatic by default**: Double-clicking the standalone portable executable or using the installed shortcut enables `--auto-exit` by default. Closing the window releases file locks so files can be moved or deleted.

#### 2. Windows PE metadata

- Added `--windows-description=agent-purge` to the standalone EXE build arguments.
- The release notes state that Windows process descriptions and digital signature display identify `agent-purge` instead of confusing it with the underlying Bun runtime.

### Installation and upgrade

#### Global npm install / upgrade

```bash
npm install -g agent-purge@latest
agent-purge web
```

#### Portable EXE / installer

Download the released standalone `agent-purge.exe` or `agent-purge-0.2.15-setup.exe` from this release's attachments.
