# agent-purge v0.2.22

### Highlights

#### 1. WorkBuddy AI international support, tested with 5.9.4

- Added `workbuddy-ai` for the international WorkBuddy AI at workbuddy.ai, independently alongside the domestic `workbuddy` harness. Either or both can be installed and uninstalled separately.
- **Observed evidence**: In a real message sent through a local CDP connection to the renderer, asking for the assistant's name after writing a persona returned the persona name. Uninstall restored the configuration and `IDENTITY.md`, `SOUL.md`, and `USER.md` bytes.
- **Identity channel**: `personalization.customPrompt` enters `<user_custom_instructions>` in `identity_context`, synchronized with `~/.workbuddy-ai/user-*/{IDENTITY,SOUL,USER}.md`.

#### 2. Corrected the primary write location to `app-config.json`

- **Symptom**: Writing only `~/.workbuddy-ai/settings.json` left the old value in the WorkBuddy settings panel, and new tasks did not follow the new persona.
- **Cause**: `PersonalizationCollector` reads `AppConfigService.get("personalization")` first and falls back to `readLegacySettings()` only if unavailable. AppConfigService's primary store is `<home>/app/app-config.json`. Domestic 5.9.3 and international 5.9.4 behave alike: when both files are written, `app-config.json` wins.
- **Fix**: Write `app-config.json` when it exists; otherwise, for older versions, write `settings.json`. Installation and uninstall remove agent-purge's own marker block from the other file while preserving other text. The write location no longer changes depending on whether the user opened the settings panel.

#### 3. Fixed detection of installation paths containing Chinese characters

- **Symptom**: WorkBuddy installations in a path containing Chinese characters could not be detected: `findTemplatesDir` returned null and `detect` reported not installed.
- **Cause**: A `.lnk` file's `LocalBasePath` uses the system ANSI code page (936/GBK on a Chinese system), but `lib/locate.mjs` decoded it as `latin1`, producing a nonexistent path.
- **Fix**: Decode using the registry `ACP` code page (gbk, big5, shift_jis, euc-kr, or windows-1252), falling back to latin1 when unavailable or bytes are invalid. The corrected lookup found the installed executable directly.

#### 4. International edition detection and capability table

- `detect` now includes `workbuddy-ai`: `WorkBuddyAI.exe`, the `~/.workbuddy-ai` configuration root, and `WORKBUDDY_AI_CONFIG_DIR` / `WORKBUDDY_AI_TEMPLATES_DIR` environment variables.
- Added the Web console icon, system-layer mapping, desktop-first `caps`, and project-rule documentation.

---

### Upgrade notes

- Both domestic and international editions now write to `app/app-config.json` when it exists. Blocks previously written to `settings.json` are automatically removed on the next `install`.
- Name and persona settings remain WorkBuddy's own cloud personal configuration. agent-purge neither writes nor clears them.

### Installation and upgrade

```bash
npm install -g agent-purge@latest
agent-purge install workbuddy-ai   # Or workbuddy, or install both
```

See release attachments for the portable executable and installer (`agent-purge.exe` / `agent-purge-0.2.22-setup.exe`).
