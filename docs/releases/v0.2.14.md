# agent-purge v0.2.14

### Highlights

#### 1. WorkBuddy dual-channel takeover and byte-for-byte restoration

- **Root cause**: Addresses the issue where changing only `customPrompt` in WorkBuddy's `settings.json` still allowed the underlying `~/.workbuddy/user-*/IDENTITY.md` (name) and `SOUL.md` (persona) to override the identity in questions.
- **Two coordinated channels**: Scans and manages all `user-*` directories, updating `IDENTITY.md` (AI name), `SOUL.md` (persona body), `USER.md` (user name), and `settings.json` (customPrompt).
- **Original-byte backups**: Saves original bytes under `stash/workbuddy-users/` and restores them on disarm without changing cloud private-configs or leaving data behind.

#### 2. Real Kilo Code binary request capture across all modes

- Supports `@kilocode/cli` 7.8.18, including the code-agent prompt (replace / strict) and managed `AGENTS.md` blocks (append).
- Captures requests for off, strict, replace, and append through an isolated loopback provider, confirming the test persona marker consistently appeared in the `system` role.

#### 3. DeepSeek Harness (DSH) capture and status synchronization

- Captures real requests from Headless, Web, and Electron CDP-based Desktop, testing request roles and section removal.
- Refactors `persist.probe` to use `hasPluginAny`, fixing inconsistent status display across desktop, web, and headless profiles.

#### 4. Console one-click updates for npm and EXE

- Queries official npm, the domestic npm mirror, and GitHub Releases concurrently when the console opens or the version badge is clicked.
- Provides version comparisons, release-note previews, and a copyable terminal installation command.
- Supports one-click npm upgrades in the Web interface and in-place portable EXE upgrades using Windows atomic file renaming.

#### 5. Web console dropdown redesign

- Replaces native Windows `<select>` popups with custom select overlays.
- Uses rounded cards, soft shadows, rotating SVG arrows, hover transitions, selected-item checkmarks, and automatic flipping at viewport boundaries.

#### 6. README internationalization

- Added `README.en.md` and `README.ja.md` and language navigation to the main README.

### Installation and upgrade

#### Global npm install / upgrade

```bash
npm install -g agent-purge@latest
agent-purge web
```

#### Portable EXE / installer

Download the released `agent-purge.exe` standalone executable or `agent-purge-0.2.14-setup.exe` from this release's attachments.
