# agent-purge v0.2.21

### Fixes

#### 1. Invalid dsh YAML patch when the home directory contains an apostrophe

- **Symptom**: A home path containing an apostrophe, such as `C:\Users\O'Brien`, produced an unescaped `file:` URL in `cordis.patch.yml`, causing dsh to fail parsing with `Unexpected scalar at node end`.
- **Fix**: Double each apostrophe as `''` before writing a YAML single-quoted scalar. Spaces and Chinese characters were already URL-encoded. Verification with the real dsh YAML parser and `import()` confirmed that patches parse and plugins load from paths containing spaces, Chinese characters, and apostrophes.

#### 2. Remove empty `node_modules` after old-layout migration

Version 0.2.20 could leave an empty `node_modules` in a profile after migrating an old plugin directory. Now the empty directory is removed only if agent-purge actually removed its own copy; it is retained unchanged if other packages remain.

### Installation and upgrade

```bash
npm install -g agent-purge@latest
agent-purge install dsh
```
