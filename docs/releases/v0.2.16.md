# agent-purge v0.2.16

### Highlights

#### 1. Desktop installation location detection

- **Four-stage lookup**: Start menu and desktop shortcuts; common roots on each drive (`X:\<name>`, `Program Files`, `Programs`, `Apps`); registry uninstall entries; then a shallow drive scan (depth 3, skipping system directories, with a 600 ms budget per drive).
- WorkBuddy, ZCode, DSH, and Antigravity can be detected on `F:\`, `D:\`, or other directories without hard-coded `D:/` or `C:/Program Files/` paths.
- `.lnk` files are parsed in pure JavaScript without PowerShell COM. Registry queries are targeted fallback operations, and results are cached.

#### 2. Configuration files no longer required for installation detection

- An existing configuration directory counts as installed. Newly installed Claude, Grok, and Codex no longer appear uninstalled before creating `settings.json` or `config.toml`.
- OpenCode detection also accepts `opencode.jsonc`, `config.json`, `auth.json`, `plugins`, or `node_modules`, rather than only `opencode.json`.
- CLI detection adds `%APPDATA%
pm`, `~/.bun/bin`, `~/.local/bin`, and `scoop\shims` fallbacks when GUI launches do not inherit a complete `PATH`.

#### 3. Corrected WorkBuddy project-rule documentation

- The earlier claim that WorkBuddy has no writable project rule file was inaccurate. It reads the first existing file among `CODEBUDDY.md`, `.codebuddy/CODEBUDDY.md`, and `AGENTS.md`, inserting it into the first turn's `<project_context>` (8,000-character limit).
- The interface now identifies this as user context, which does not override system identity. Identity still uses `customPrompt` in `settings.json`.

#### 4. Other changes

- Technical details now show an installation directory and its source: shortcut, drive-root scan, shallow drive scan, or registry.
- Fixed a duplicate `kilo` key in `web/server.mjs` that caused static-check errors.
- `scripts/verify-zcode-real.mjs` no longer hard-codes `D:/zcode`.

### Installation and upgrade

#### Global npm install / upgrade

```bash
npm install -g agent-purge@latest
agent-purge web
```

#### Portable EXE / installer

Download the released standalone `agent-purge.exe` or `agent-purge-0.2.16-setup.exe` from this release's attachments.
