# agent-purge v0.2.25

### New support

#### 1. Antigravity (Google desktop app and `agy` CLI)

- **Background**: The matrix previously listed Antigravity as `binary-patch / inject: false`, and `agent-purge antigravity` reported that it could not be changed. Investigation identified a writable configuration channel that does not require binary modification.
- **Injection location**: `~/.gemini/config/AGENTS.md`. Both desktop and `agy` read `~/.gemini/config/`; without frontmatter this file is an `always_on` global rule. The host inserts it into `<user_rules>` in `systemInstruction`, preceded by `These rules take precedence over any other instructions`.
- **Captured evidence**: On local CLI `agy` 1.5.3 and desktop language service 1.23.x, with isolated HOME and loopback capture, all four modes (`off / strict / replace / append`) captured the main request and exited with code 0. Markers appeared in the **system layer** (`systemInstruction`), never in `user`. System lengths were 15,378 characters for off and 15,895 / 15,844 / 15,843 for strict / replace / append. `<user_rules>` followed `</identity>`.
- **Real-model verification**: After CLI login, three identity questions using hand-written equivalent content at the same `~/.gemini/config/AGENTS.md` location returned the new persona instead of Antigravity. The capture above verified agent-purge's managed block enters `systemInstruction` through the same channel. A single run combining agent-purge's write with a real model was **not run**, because the local proxy was interrupted.
- **Residual identity**: `You are Antigravity, ...` remains in `<identity>`; the rule's precedence statement overrides it rather than deleting it. Actual removal would require equal-length replacement of `resources/bin/language_server.exe` (invalidating its signature and being overwritten on update), or manually choosing a custom agent in the GUI. `~/.gemini/config/agents/<name>.md` can replace the entire `<identity>`, but none of the 34 tested `settings.json` keys provided an automatic default-agent setting.
- **Channels**: Only persistent `install` is available. `shim` is unavailable because the CLI is named `agy`, not `antigravity`; `slash` is unavailable because there is no equivalent `/purge` entry point.
- **CLI detection**: `agy` installs at `%LOCALAPPDATA%\agy\bin\agy.exe`, often absent from a GUI process's inherited PATH. Detection adds that fixed fallback and treats `~/.gemini/config` as evidence the app has been run.

#### 2. Gemini native protocol capture

`bench/capture-provider.mjs` previously recognized only `system`, `instructions`, `messages`, and `input`, missing Gemini's `systemInstruction.parts` and `contents[]`. It now recognizes `/v1beta/models/<model>:streamGenerateContent`, extracts `systemInstruction.parts`, and returns SSE responses using `candidates[].content.parts`. `agent-purge verify antigravity` reuses this path.

### Fixes

- **Incorrect shim availability**: `resolveReal("antigravity")` always returns `null` because the command is `agy`, but the old `!shimWhy || (desktop && hasCli)` logic marked the channel available when the binary existed, producing a nonfunctional UI switch. An explicit exclusion for harnesses whose CLI name differs now reports the actual reason.
- **Temporary launch removed persistent blocks**: An initial install-then-uninstall implementation removed existing persistent blocks after `agent-purge antigravity` completed (`stash.before` was null, leading uninstall to delete the file). `temporaryAntigravity` now restores original bytes, preserving both persistent blocks and user rules. Three regression tests cover an existing persistent block, a clean machine, and existing user rules.

---

### Installation and upgrade

```bash
npm install -g agent-purge@latest
agent-purge arm antigravity --install
```

Install Antigravity first, either the desktop app or `agy` CLI. `agent-purge antigravity` can also launch the CLI with a persona and restores the original bytes on exit.

See release attachments for the portable executable and installer (`agent-purge.exe` / `agent-purge-0.2.25-setup.exe`).
