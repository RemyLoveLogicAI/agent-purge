# agent-purge v0.2.33

### More reliable PI-Desktop channel

- Improved hot-switch compatibility so the current persona remains effective when switching models, avoiding a misleading enabled status when it has not taken effect.
- `/purge off` now more completely restores the native identity immediately within a session.
- Updated the support matrix and documentation in three languages.

### More accurate Web console (#18)

Uninstalled hosts are no longer shown as available for takeover; switches appear only for hosts that can actually be managed.

### Verification

At release time, `npm test` passed 90/90 tests and `npm run check:repo` passed.
