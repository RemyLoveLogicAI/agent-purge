# agent-purge v0.2.26

### Improvements

#### 1. Antigravity icon and channel descriptions in the Web console

- **Icon**: Replaced the initial-letter placeholder with `icon.png` extracted from the local `resources/app.asar` (512×512, SHA256 `b27f0e4a…`, matching the asar integrity record), saved as `web/assets/antigravity.png`.
- **Transparent background and crop**: The original rounded white backing left the colored `A` occupying only 60% of the canvas, making it visually lighter than other icons at 24px. The icon was regenerated at 128×128 (11 KB), with white converted to transparent, cropped to the ink bounds, and 14% padding. Corner alpha is 0, and its appearance aligns with other icons at 24, 28, and 34 pixels on light and dark backgrounds.
- **Channel descriptions**: The drawer reports actual capabilities: persistent global configuration and current-project rules are available; in-session hot switching and command entry each state their actual limitations, replacing the obsolete binary-patch-only description.
- **Verification page**: `agy` is recognized as an isolated CLI harness. `/api/verify` uses the same Gemini native capture path (`systemInstruction.parts`) and returns `captured / 15843 chars / system layer`.

Local Web console checks found the `antigravity` icon with `naturalWidth=128`; two off-to-on cycles used `/api/arm` and deleted and recreated `~/.gemini/config/AGENTS.md`; `/api/verify` returned `injected.sys=true` and `chars=15843`.

#### 2. magpie gateway plugin: visual scope selection

- **`disabledAgents` field**: An exclusion list in plugin options takes priority over the `agents` allowlist. `hooks.js` checks it first; matches pass through unchanged with `report("skipped", 0)`.
- **Plugin management page**: Choose all agents, only selected agents, or exclude selected agents. Presets include claude, codex, opencode, pi, dsh, antigravity, hermes, cursor, and gemini; custom identifiers such as `kilo` or `zcode` can also be added without editing JSON.
- **Status line**: Exclusion mode displays excluded agents, corresponding to the allowlist mode's only-selected wording.
- **Persona fallback**: If `gen-personas.mjs` has not run, the page shows the built-in Neutral Assistant and Minimal personas instead of an empty list.
- **Regression coverage**: Added three `test/magpie/hooks.test.mjs` cases for excluded matches and normal rewriting across protocols when not excluded; eight `test/magpie/page.test.mjs` cases cover all three scope modes, selections, status text, custom agents, and clearing and hiding the panel in all-agents mode.

> The plugin is not included in the agent-purge npm package. Clone the repository and install with `magpie plugin add` as described in `magpie-plugin/README.md`. These changes are distributed with the repository.
