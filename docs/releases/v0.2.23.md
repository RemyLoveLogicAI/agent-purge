# agent-purge v0.2.23

### Fixes

#### Fixed DSH session hot-switch plugin `ReferenceError: hostProfile is not defined` (Issue #12)

- **Symptom**: Enabling the `agent-purge-slash` hot-switch plugin with DSH 0.2.2 or 0.2.1 raised `ReferenceError: hostProfile is not defined at Object.apply [as callback]`, preventing activation.
- **Cause**: Version 0.2.20 moved the plugin package into the data directory and added dynamic profile inference from the host's `profileContext` in `apply(ctx)`. The `slashSource` template omitted `hostProfile(ctx)` and declared top-level `const PROFILE`, which would also cause `TypeError: Assignment to constant variable` after adding the function.
- **Fix**: Added `hostProfile(ctx)` to `slashSource` and declared `let PROFILE = PROFILE_FROM_PATH;` at the top level, matching `residentSource`. Added unit tests that dynamically load the generated `slashSource` module and execute `apply(ctx)`, covering profile extraction, `/purge on|mode|status|off` command registration, and state writes.
