# agent-purge v0.2.36

Version 0.2.35 failed release acceptance, so no npm or GitHub Release was published. Its original tag remains without rewriting history. This version includes all of its fixes and more robust Windows acceptance checks.

## Windows desktop (#20)

- Statically linked the MinGW runtime to eliminate missing-DLL startup error `0xC0000135`. The build checks the import table and refuses release on anomalies.
- Logs native-host startup failures and falls back to a browser; fixed duplicate windows.
- Running windows or launchers block overwrite installation and uninstall to prevent in-use EXE/DLL leftovers.
- Configuration is reversed only after uninstall confirmation. Serious restoration failures still block uninstall; old records can be skipped with credentials retained.
- Cleanup previews do not write user data, migrate configuration, or roll back journals.
- Tools are presented consistently without an exclusive badge; independent persona settings remain.

## Acceptance and artifacts

- Real Windows installation, reinstallation, native windows, singleton behavior, closing, conflict handling, and uninstall.
- Windows, Linux, and macOS tests across Node 20/22/24 and npm tarball acceptance.
- Native Linux x64 and ARM64 runners each verify standalone binaries, portable installation, Debian install/run/uninstall, and optional AppImage.
- Fixed Windows acceptance dependencies on inherited PowerShell environment and short query timeouts. Original failures are retained and installer logs uploaded, without weakening release checks.
- Windows ZIP, setup, standalone EXE; Linux x64/ARM64 standalone, tar.gz, deb, AppImage; macOS arm64/x64 DMG. Checksums are in `SHA256SUMS.txt`.
- The macOS DMG remains unsigned and unnotarized. Manually allow it through the system security prompt on first launch.
